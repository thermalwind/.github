# Source

The originals: documents received, exports, contracts, e-mails — and the originals a person
wrote here. **No tool modifies anything in this folder.** An agent reads it.

Why the rule is absolute: a source that gets "improved" is no longer evidence. The moment an
agent edits an original, every claim that cites it becomes unverifiable — and the
uncertainty never surfaces again. Corrections belong in the compiled layer, with a pointer.

Add material here, then let ingest distil it into `knowledge/`.
