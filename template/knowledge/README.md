# Knowledge

The compiled layer: pages distilled from `Source/`, plus the analysis and decisions a person
wrote here. This is what an agent reads to answer a question, so that nothing has to be
re-derived from raw files on every ask.

Two kinds of page live here, and they behave differently:

- **Distilled from sources** — regeneratable. Delete it and rebuild it; the original still
  has the truth. These pages carry a pointer back to what they came from.
- **Original analysis, decisions, minutes** — preserved. Nobody can regenerate a decision.

A human edit to a page is an instruction: the agent stops rewriting that page and works
around it.
